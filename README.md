# python00

42 Heilbronn — Python module 00: language fundamentals.

Eight small gardening-themed scripts covering the basics. Every exercise is
driven by `input()` and prints its result; nothing takes arguments or reads
files yet.

| | Topic |
|---|---|
| `ex0` | `print` and string literals |
| `ex1` | `input()` and printing user data |
| `ex2` | `int()` conversion and arithmetic on input |
| `ex3` | Summing several inputs |
| `ex4` | `if` / `else` on a numeric threshold |
| `ex5` | Comparison operators and branching |
| `ex6` | The same countdown written twice — with a `for` loop, and recursively via a helper function |
| `ex7` | Function parameters and `elif` chains |

## Running

```
python3 ex0/ft_hello_garden.py
```
